# Context-selection examples

## Focused Python edit

Include:

```yaml
communication:
  - lead_with_result
preferences:
  - python_snake_case
  - minimal_dependencies
  - complete_files_when_creating
approval:
  - ask_before_installing_dependencies
triggered_modes: []
```

Do not include daily planning, timer, or commitment-ledger rules.
